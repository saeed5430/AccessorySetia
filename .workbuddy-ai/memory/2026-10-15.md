## Auth audit: Telegram / Bale / dev mode (read-only, no code changed)

Verified against official docs (curl: core.telegram.org/bots/webapps, docs.bale.ai/miniapp).

CONFIRMED CORRECT in backend/accounts/services.py:
- secret_key = hmac.new(b"WebAppData", bot_token, sha256) matches doc "HMAC_SHA256(<bot_token>, 'WebAppData')".
- data-check-string = all fields except `hash`, sorted, joined by \n; hash = hmac.new(secret_key, dcs, sha256).hexdigest().
- Keeping `signature` inside the data-check-string is CORRECT for the bot-token HMAC scheme (excluding it applies only to Ed25519 third-party validation).
- auth_date freshness check (INIT_DATA_MAX_AGE = 24h) present.
- Same algorithm is valid for Bale: Bale docs use identical HMAC scheme + constant "WebAppData".

P0 BLOCKING: frontend/index.html (and built dist/index.html) does NOT include the SDK scripts. Telegram requires <script src="https://telegram.org/js/telegram-web-app.js"></script> and Bale requires <script src="https://tapi.bale.ai/miniapp.js"></script>, both before any other script in <head>. Without them window.Telegram / window.Bale are undefined, so getPlatform() always returns "web" and the app always takes the dev mock branch. Real auth can never run.

P1:
- isDev = (platform === "web") is NOT gated by import.meta.env.DEV, so a production build opened in a normal browser shows the mock "logged in" user.
- Prod refresh-cookie path risk: REFRESH_COOKIE_PATH unset -> "/api/account/" but .env.production VITE_API_BASE_URL = "/backend/api/account"; cookies are path-scoped so refresh cookie may not be sent. Needs verification against the reverse proxy.

P2:
- Bale WebAppUser has no last_name (id, first_name, username, allows_write_to_pm, photo_url) -> Bale users always arrive without last_name and must fill it.
- CORS_ALLOWED_ORIGINS in backend/.env is localhost-only.
- DEBUG hardcoded False in settings.py (DJANGO_DEBUG ignored) -> REFRESH_COOKIE_SECURE=True always.
- backend/.env has both bot tokens set; DB_NAME=setiyaap_setiya (MariaDB); db.sqlite3 is a leftover.

P3: expand() never called; getBaleUser() in bale.ts is dead code (Platform.ts inlines Bale user extraction); messengerUser effectively unused.
